# History Versions

LIQUID-Agent's early-access releases are reviewed snapshots of the liquid-biopsy
research workspace. Development can advance beyond the public release; a
development feature is not automatically available in an installed release.

## Versions

| Version | Release summary |
| --- | --- |
| [V0.1](v0.1.md) | First early-access testing release: the local research workspace, established liquid-biopsy workflows and reviewed model-management updates. It excludes the 3 October 2026 scientific expansion. |

## How this archive is organized

Each release receives its own decimal version label and page: **V0.1**, then
**V0.2**, and so on. The **History Versions** navigation uses those same labels; each version page
brings its summary and Capability Atlas together. Only releases that have actually been made
available are added; the sequence above is an archive convention, not a promise
of a future release or its contents.

Read the relevant version summary before following capability examples. The
[V0.1 Capability Atlas](v0.1.md#capability-atlas) provides an illustrated
view of the workspace; its version and scope notices identify which edition it
describes.

| 版本 | 版本概要 |

## 归档规则

每个版本使用独立的小数点版本编号和页面，例如 **V0.1**，后续依次为 **V0.2**
等。**历史版本**导航沿用同一编号，每个版本页面集中展示总结与功能画廊。只有实际提供的版本才会加入
目录；上述序列仅说明归档规则，不代表已经承诺后续版本或其内容。

使用功能示例前，请先核对对应版本的总结。[V0.1 能力图谱（Capability Atlas）](v0.1.md#capability-atlas)
以实操画面介绍工作区；其版本与范围说明标明了所展示的版本。
