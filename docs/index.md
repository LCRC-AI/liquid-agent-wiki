# LIQUID-Agent User Guide

LIQUID-Agent is a local-first workspace for liquid-biopsy analysis. It helps you attach supported datasets, inspect their structure, review an analysis plan, run valid steps, and examine locally generated figures, tables, and reports.

Start with [installation](getting-started/installation.md), then follow [your first analysis](getting-started/quickstart.md). The [illustrated workspace walkthrough](getting-started/workspace-walkthrough.md) shows a complete cfRNA example. Use the Guides section for preprocessing, encoding, cfDNA analysis, assay tables, model configuration, privacy, linked tasks, images, and reviewed skills.

LIQUID-Agent is a research tool, not a diagnostic service. Check input requirements and limitations before interpreting any result.

## Explore your release

The first early-access release is **V0.1**. Read its [release summary](releases/v0.1.md) for the included capabilities and limits; it does **not** include the 3 October 2026 major scientific upgrade.

Open the [Capability Atlas — V0.1 gallery](getting-started/capability-atlas-v0.1.md) for screenshots of the main interactions. Both **Capability Atlas** and **Version History** have their own sections in the sidebar. The [version archive](releases/index.md) groups release records by decimal version number.

# LIQUID-Agent 用户指南

LIQUID-Agent 是一个本地优先的液体活检分析工作区，可帮助您添加受支持的数据集、检查数据结构、审阅分析计划、执行有效步骤，并查看在本地生成的图形、表格与报告。

建议先阅读[安装说明](getting-started/installation.md)，再完成[第一次分析](getting-started/quickstart.md)。[工作区图文教程](getting-started/workspace-walkthrough.md)展示了一套完整的 cfRNA 示例。指南部分还包括预处理、编码、cfDNA 分析、检测表格、模型配置、隐私、任务链接、图片追问和技能审阅。

LIQUID-Agent 是科研工具，不是诊断服务。解释结果前，请检查输入要求与功能限制。

首个早鸟测试发布版编号为 **V0.1**。请查看[版本总结](releases/v0.1.md)了解已包含的能力与限制；该版本**不包含** 2026 年 10 月 3 日的科学功能大升级。
